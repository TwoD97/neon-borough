The custom layout uses ui_font "Space Grotesk" and terminal font "Geist Mono".
Geist Mono ships with Herdr; it is not duplicated in this package.
Herdr loads .ttf/.otf files from mod fonts directories on the next look change.
To use the same fonts as global fallbacks, merge these two settings.json fields:
  "font": "Geist Mono"
  "ui_font": "Space Grotesk"
Keep the rest of your existing settings. Font sizes and zoom are unchanged.
